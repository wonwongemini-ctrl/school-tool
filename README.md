# 학교 업무 도구

## 한글 문서 도구 한눈에 (2026-11-12)

| 파일 | 도구 | 하는 일 |
|---|---|---|
| `hwp2hwpx.html` | HWP·HTML → HWPX 변환 (v2.2) | 옛 한글 파일, AI가 쓴 글(.html·붙여 넣기)을 .hwpx로 |
| `hwpx-merge.html` | 한글 파일 합치기 (v1.0) | 여러 .hwpx(.hwp)를 하나로 · 표지·목차·쪽 번호 |
| `print-helper.html` | 출력 도우미 (v1.0) | 명단 한 번으로 명패·라벨·견출지·등록부. 인쇄·HTML·한글(.hwpx) |

`nameplate.html`, `labels.html`, `sign-sheet.html`(11-11 v1.0)은 출력 도우미로 합쳤습니다. 예전 주소로 열면 출력 도우미의 그 화면(`print-helper.html?make=plate|label|sign`)으로 넘어가고, 지난 판은 `versions/`에 있습니다.

이 도구들과 학교운영위원회 운영업무 도우미는 **같은 코드(src/shared)**를 씁니다. 학교 정보(학교명·주소 등)는 이 주소(wonwongemini-ctrl.github.io) 아래 도구끼리 같이 씁니다.

### 소스와 빌드

- `src/shared/`: 공유 코드의 **원본**(문서 엔진, 합치기, HTML 변환, 명패, 라벨, 서명부, .hwp 변환 엔진, 학교 정보, 화면 부품, 명단 읽기 `roster.js`, 자 있는 미리보기 `print_preview.js`, 거꾸로 면 한글 파일 `upside_hwpx.js`).
- `src/tools/<도구>/page.html`: 도구별 화면. `/*__SHARED:파일__*/`, `/*__VENDOR:파일__*/` 줄을 빌드가 채웁니다.
- `python3 build.py` → 맨 위 폴더에 `<도구>.html`이 만들어집니다. 올릴 때는 이 HTML 파일들과 `src/`, `build.py`, `README.md`를 함께 올립니다.
- 운영업무 도우미 소스에서는 `python3 build.py --shared <이 저장소>/src/shared`로 가져가 씁니다.

## 출력 도우미 (`print-helper.html`)

명단을 한 번 넣고 명패·라벨·견출지·등록부를 함께 만듭니다. 왼쪽은 한 화면에 질문 하나, 오른쪽은 위·왼쪽에 mm 자가 있는 미리보기(바로 반영)입니다.

- 명단 규칙: 맨 끝 = 이름, 바로 앞 = 직위, 그 앞 = 소속. 칸 나누기는 탭(엑셀 복사)·쉼표. 첫 줄이 머리글(성명·직위·소속·비고)이면 그 순서대로. 괄호는 바로 앞 낱말에 딸린 작은 글씨(등록부에서는 이름 뒤 괄호 → 비고 칸).
- 라벨: 라벨지 규격 고르기, 쓰던 라벨지는 미리보기에서 시작 칸 누르기, 검은 테두리·배경 그림은 [모든 라벨에] / [칸 골라 넣기], 그림은 칸에 맞게 늘리기 또는 잘라 채우기.
- 저장: 인쇄 · HTML · 한글(.hwpx). 명패·견출지의 거꾸로 면은 한글이 돌린 글상자의 글자를 돌리지 않아서, 이 PC 글꼴로 그린 그림으로 넣습니다(아랫면은 고칠 수 있는 글상자).

## HWP → HWPX 변환 (`hwp2hwpx.html`)

한글 프로그램 없이 옛 한글 파일(.hwp)을 새 형식(.hwpx)으로 바꿉니다.

- 파일은 인터넷으로 올라가지 않습니다. 브라우저 안에서 파이썬(Pyodide)이 돌아가며 변환합니다.
- 파일을 끌어다 놓으면 됩니다. 폴더째 넣을 수 있고, 여러 개는 zip으로 한꺼번에 받습니다.
- 크롬·엣지에서는 폴더를 고르면 원본 옆에 .hwpx를 바로 저장할 수 있습니다.
- HTML 파일 하나로 동작합니다. GitHub Pages 주소로 열어도 되고, PC에 저장한 파일을 열어도 됩니다.
- 처음 열 때만 변환 엔진을 공개 CDN(jsdelivr, 안 되면 unpkg)에서 내려받습니다.

### 변환 범위

| 그대로 옮겨짐 | 변환 불가 |
|---|---|
| 글자 모양·문단, 표, 그림, 도형, 글상자, 머리말·꼬리말, 바탕쪽, 쪽 번호, 각주·미주, 수식, 숨은 설명, 누름틀, 하이퍼링크, 책갈피, 덧말, 글자 겹치기, 새 번호 지정, 양식 개체 | 배포용 문서, 암호 문서, HWP 3.0 이하 |

시험 결과: 시험 문서 84개를 모두 정상 HWPX로 바꿨고, 원작 Java hwp2hwpx의 결과와 요소 단위로 대조해 같게 맞췄습니다. 남은 차이는 원작의 버그(표 뒤 글자가 표 안으로 들어감, 그림 설명 줄바꿈이 두 번 들어감)이고, 이 부분은 원본 문서 쪽이 맞도록 두었습니다.

### 버전

`hwp2hwpx.html`은 늘 최신판입니다(허브 바로가기는 이 파일을 엽니다). 지난 판은 `versions/` 폴더에 `hwp2hwpx_v버전.html` 이름으로 보관합니다. 지금 쓰는 판은 화면 맨 위와 맨 아래에 표시됩니다.

| 버전 | 날짜 | 바뀐 점 |
|---|---|---|
| v2.2 | 2026-11-11 | .html 파일과 AI 글 붙여 넣기도 .hwpx로(문서 틀: 기본·가정통신문·내부 보고), 학교 정보 같이 쓰기. 이름을 'HWP·HTML → HWPX 변환'으로 |
| v2.1 | 2026-10-16 | 메모리·속도 개선(변환 결과는 v2.0과 같음): 큰 문서 메모리 약 1/4로(10MB 문서 기준 1.1GB → 약 280MB), 결과 검사를 조금씩 읽는 방식으로, zip 받기를 복사 없이, 큰 파일 뒤 엔진 자동 재시작, 쓰지 않는 코드 정리로 파일 크기 545KB → 333KB |
| v2.0 | 2026-10-16 | 원작(Java hwp2hwpx)과 같은 방식으로 다시 만듦: 원본에 없던 취소선이 생기던 문제, 빈 줄 크기·표 칸 여백·단 나누기 문제(가정통신문이 몇 줄 아래에서 시작하던 현상) 수정. 그림·도형·글상자·양식 개체·바탕쪽, 누름틀·하이퍼링크·책갈피가 기능 그대로 옮겨짐 |
| v1.0 | 2026-10-16 | 첫 판: 브라우저 안 변환, 폴더·여러 파일 변환, zip 내려받기, 배포용·암호 문서 안내 |

새 판을 올릴 때: ① 지금 `hwp2hwpx.html`을 `versions/hwp2hwpx_v이전버전.html`로 복사해 두고 ② 새 파일로 `hwp2hwpx.html`을 바꾼 뒤 ③ 위 표에 한 줄 추가합니다.

### GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만듭니다(예: `school-tools`). **Public**으로 만들어야 무료로 Pages를 쓸 수 있습니다.
2. 저장소 화면에서 **Add file → Upload files**를 누르고 `hwp2hwpx.html`, `README.md`, `versions` 폴더를 끌어다 놓은 뒤 **Commit changes**를 누릅니다.
3. **Settings → Pages**에서 *Source*를 `Deploy from a branch`로, *Branch*를 `main`, `/ (root)`로 고르고 **Save**를 누릅니다.
4. 1~2분 뒤 다음 주소로 열립니다.
   `https://<GitHub아이디>.github.io/school-tools/hwp2hwpx.html`

> ⚠️ `예원초_업무·내선·위치_찾기.html`은 **올리지 마세요.** 와이파이·사이트 계정 비밀번호가 들어 있어서, 공개 저장소에 올리면 누구나 볼 수 있습니다.
